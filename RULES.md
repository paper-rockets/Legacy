# Project Rules & Permanent Memory

## 1. Strict Pinpoint Edits
We only modify the exact 2 to 5 lines responsible for a specific fix, never replacing or regenerating whole sections of the file.

## 2. Visual Invariant Lock
All lighting values, sun horizon offsets, track arrays, and material settings are treated as strictly protected constants.

## 3. Extraction Rules
Whenever asked to extract, pull, or retrieve code, act as a strict text parser.
Extract the code VERBATIM.
DO NOT refactor, optimize, format, fix bugs, or improve the code in any way.
Do not change variable names, indentation, or syntax.
Output ONLY the exact raw text as it exists in the source.

## 4. No Icons / No Emojis Rule
- NEVER use icons, emojis, unicode symbols, or decorative glyphs anywhere.
- Do NOT use icons in text responses, headers, bullet points, file trees, UI designs, buttons, badges, tables, or code.
- Keep all communication, documentation, terminal scripts, batch files, and UI elements completely clean, plain text, professional, and 100% icon-free.
